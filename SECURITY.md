# Security policy

BuyingMesh is an agent-facing procurement service. Please do not include API keys,
private keys, payment signatures, credentials, buyer personal data or supplier
documents in a public issue.

For a suspected vulnerability in this adapter or the public MCP endpoint, email
`ops@buyingmesh.com` with the affected endpoint, a reproducible request and the
minimum evidence needed to validate the report. Do not attempt to access other
users' data or disrupt the service.

The public sandbox is disposable and order settlement is simulated. Production
settlement, escrow and supplier data are subject to separate access controls.
